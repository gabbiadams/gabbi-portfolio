# Gabbi Adams Portfolio

A simple HTML and CSS portfolio with six projects and your supplied logos. The horizontal logo appears on desktop; the stacked logo appears on small screens. Click any screenshot to open its full-size image in a new tab.

## Preview
Open `index.html` in your browser. No installation or build required.

## GitHub Pages
1. Unzip the package.
2. Upload the contents of `gabbi-portfolio` to your GitHub repository. Keep `index.html`, `styles.css`, and `assets` at the root.
3. In Settings → Pages, choose Deploy from a branch, then main and / (root). Save.
4. Open the website address shown in Pages settings when publishing completes.

If replacing the previous version, replace index.html and styles.css, upload the two logo images in assets, and remove the old script.js. Existing project screenshots can stay.

## Editing
Edit project text and links in index.html. Edit the layout in styles.css. Screenshots are in assets and were extracted from the assignment PDF.
