Checkpointer

I designed Checkpointer for endurance cycling and running events where participants may travel for hours or multiple days between checkpoints. It helps racers organize checkpoint information, estimate arrival times, identify resources ahead, and plan around operating hours. Local storage keeps important information accessible in remote locations, reducing the mental calculations required when a racer is fatigued.

Software: TypeScript, React Native, Expo, SQLite

Skills: Offline-first design, Local database management, Application architecture, Human-centered problem solving

Wear to Ride

Every fall and spring, I find myself trying to remember which clothing worked best for different riding conditions. I built Wear to Ride to log clothing, weather, and comfort levels, then use previous ride data to inform recommendations for future rides. The portfolio also includes a Community Board feature concept that extends the experience to shared rider insights.

Software: TypeScript, React Native, Expo, PostgreSQL

Skills: Mobile UI design, Full-stack development, Database design, API integration
